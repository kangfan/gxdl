IGuxuEntryLoadingView 接口：
 void SetProgress(float progress, string message)
  progress 是 0..1，单调递增，来自真实配置、存档、入场资源加载步骤。
  message 是阶段提示。界面可以平滑显示，但不得自行增加目标进度或调用 Home。
 bool IsComplete { get; }
  只在收到 progress == 1 且屏幕上的进度条已到 100% 后返回 true。
  如有 Loading 收尾动效，也应等动效结束再返回 true；流程最多等 30 秒。

父节点为 750 x 1334，已经 FitPage；所有界面对象和播放脚本应放在 parent 下。
父节点由流程管理，完成或退出账号时自动隐藏并销毁，界面不自行切换页面。
接口在 Unity 主线程调用。Begin 时立即 SetProgress(0)，资源就绪后 SetProgress(1)。
编辑器每次登录都在 IsComplete 后清除 Loading、播放开场，再创建 Home，忽略已观看记录。
打包版本保持首次进入播放开场；已观看账号直接 Home。不会删除或重置原有观看记录。
自然播放完或主动跳过才写入已观看标记；中断不记完成；账号标记在本设备隔离。
加载失败由流程统一显示重试/返回登录，界面无需自制错误弹窗。
未实现 CreateEntryLoadingView 时流程会停留错误页，不会跳过 Loading 直接进游戏。

普通编辑器 Play 和所有构建默认显示登录；只有 GXDL > Accounts > Preview Gameplay (Offline) 及显式玩法 QA 可以进入本次编辑器离线预览，退出 Play 后恢复登录入口。
不要添加正式包免登录按钮。测试替身只在 UNITY_EDITOR 编译，不能用于真机认证。
